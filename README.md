# Card Dungeon

## Описание проекта

Учебный проект карточной roguelike-игры, в которой игрок управляет волшебницей, исследующей разветвлённое подземелье в поисках новых заклинаний.

Подземелье состоит из связанных комнат с противниками, случайными событиями, магазинами и привалами. Игрок продвигается вперёд, выбирая доступные комнаты.

Бои проходят в пошаговом режиме. Способности волшебницы представлены картами заклинаний, которые расходуют ману. Игрок управляет колодой, использует стопки добора и сброса, получает новые карты и улучшает их. Забег заканчивается победой над финальным боссом или поражением при потере всего здоровья.

Проект включает реализации на **C#** и **C++**.

## Сборка и запуск

### C# версия

Требуется установленный .NET SDK. Выполните команды из директории C#-проекта, содержащей файл `.csproj`:

```bash
dotnet build
dotnet run
```

### C++ версия

Требуются CMake, Ninja и компилятор с поддержкой C++17. Команды выполняются из директории, содержащей `CMakeLists.txt`.

Сборка:

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

Запуск в Windows:

```powershell
.\build\CourseProjectCPP.exe
```

Запуск в Linux или macOS:

```bash
./build/CourseProjectCPP
```
