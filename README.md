# Название игры (Placeholder)

## Описание проекта
Проект представляет собой программу для проведения одиночной игровой сессии в формате пошаговой карточной стратегии с элементами rogue-like[cite: 1]. Целевая аудитория игры — пользователи, которым интересны пошаговые тактические бои и механика сбора колоды (deckbuilding)[cite: 1].

## Игровой процесс
* **Старт:** Пользователь начинает игру со стартовым набором карт[cite: 1].
* **Исследование:** Игровой мир представляет собой генерируемое подземелье в виде графа развилок[cite: 1]. На каждом шаге игрок выбирает следующий узел карты: бой, случайное событие, торговец или привал[cite: 1].
* **Боевая система:** В комнатах с боем происходит пошаговое сражение[cite: 1]. Игрок добирает карты из своей колоды и тратит ману на их розыгрыш для защиты, атаки или наложения эффектов[cite: 1].
* **Ход противника:** В свой ход враг выполняет запланированное действие и передает урон или эффект игроку[cite: 1].
* **Прогрессия:** Побеждая противников, игрок получает новые карты и усиливает свою колоду, продвигаясь по подземелью[cite: 1].
* **Окончание сессии:** Игра заканчивается победой при убийстве финального босса в конце подземелья или поражением при гибели персонажа[cite: 1].
